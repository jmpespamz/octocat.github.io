Platform

Everything an agent needs, already running.

You bring the model and the tools. Strandsagents Cloud handles where the agent runs, how it scales, and what you can see afterward.

Edge deployment in 42 regions

Each request goes to the nearest healthy region. If one region fails, traffic moves in under 200 ms.

Secrets vault

Store API keys once. Agents read them at runtime and never write them to logs or images.

Scale to zero

Idle agents cost nothing. Replicas start in under a second when traffic arrives.

Traces for every run

Each model call, tool call, and token count is traced by default. Open any run and see why the agent chose a tool.

Guardrails

Redact personal data, block unsafe tool inputs, and cap spend per user before a request reaches a model.

Canary rollouts

Send a small share of traffic to a new version first. Roll back in one command if error rates rise.

Developer experience

Your agent, in plain Python.

Tools are ordinary functions with type hints. Strandsagents Cloud reads the signatures, builds the tool schema, and wires up tracing.

  • Works with any major model provider
  • Tool schemas generated from your type hints
  • Deploys straight from your repository
  • Rollbacks in one command
# agent.py
from strandsagents import Agent, tool

# Tools are plain Python functions.
@tool
def lookup_order(order_id: str) -> dict:
    """Fetch an order from the warehouse."""
    return warehouse.get(order_id)

agent = Agent(
    model="claude-sonnet",
    tools=[lookup_order],
    guardrails=["pii-redaction"],
    max_spend_per_user=0.50,
)

agent.deploy(regions="auto", min_replicas=0)
